# VolunteerHub
VolunteerHub was developed to make it easier for people to discover and join various volunteer programs through one platform. It also helps NGOs promote and manage their programs, while an administrator oversees NGO accounts to ensure proper management and build trust among users.

## a. Project Title & Description

**VolunteerHub – Centralized Volunteer Program & Community** is a web-based platform that connects volunteers with NGOs and community programmes. Users can browse volunteer opportunities, while registered users can manage their activities through their respective accounts.

## b. Features Included

- User registration and login for volunteers and NGOs.
- Separate dashboards for Admin, Volunteer and NGO.
- Browse and view available volunteer programmes.
- Volunteers can register for programmes and view their registrations.
- NGOs can add, edit and delete their own programmes.
- Admin can manage user accounts, NGO applications and programmes.
- Demo accounts and sample programmes are provided for testing.

## d. Frameworks/Libraries Used

- **HTML5** – Web page structure.
- **CSS3** – Page layout and styling.
- **Vanilla JavaScript** – Login, registration and dashboard functions.
- **Browser LocalStorage** – Stores demo accounts, user data, programmes and registrations.
